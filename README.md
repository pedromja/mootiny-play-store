## O que só tu podes fazer

1. Publicar o jogo na web (Grok → partilhar / publicar) para ter um `https`
2. Criar conta em [play.google.com/console/signup](https://play.google.com/console/signup) — 25 USD, uma vez
3. Gerar o `.aab` em [pwabuilder.com](https://www.pwabuilder.com)
4. Convidar **12 testadores** durante **14 dias** (regra da Play para contas pessoais novas)
5. Premir Enviar
